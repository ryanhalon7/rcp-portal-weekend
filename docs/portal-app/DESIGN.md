# Home / Dashboard

Application: [portal-app](../../portal-app/). Commands and code paths below are relative to that app folder unless stated otherwise.

Build a working, local dashboard prototype without opening or reading RCPAb2b. PLAN.md supplies the purchasing context; stageshow supplies craft and visual hierarchy. This is a standalone review surface, ready to translate into Flask templates once approved; it does not replace or connect to the existing platform.

Medium: full-viewport, responsive application with realistic content. No fake browser frame, decorative animation, or miniature scaling. Desktop: 232px persistent sidebar, 76px utility bar, spacious workspace. Phone: labeled navigation drawer, location selector, stacked reorder rows, visible ordering action.

Focal task: reorder frequently purchased supplies. Secondary context: recent orders and account items needing attention. Payoff: quantities enter the current location cart with clear confirmation. Quick Order, location switching, search, order details, date filters, notifications and list selection work locally. Other navigation opens an honest scope notice.

Look: cool gray canvas, white surfaces, dark slate type, one blue action accent; Phosphor icons. Status colors convey meaning. Plain text RCP America wordmark until approved brand artwork is supplied. Gold: static-card, preserving its sidebar/list/detail hierarchy and kit Row, Card, Button, Badge and Avatar primitives; adapting framing to a full working screen, as requested. Realistic fidelity, real content throughout. No live delivery promises or invented account credit.

All records are demonstration data, labeled in the shell. Location carts persist separately in localStorage. No orders are submitted and no financial records are created. Off-list items stay marked as requiring approval.
